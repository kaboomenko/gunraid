## Нужно до старта этапа 1

1. **Подтверждение** стека, архитектуры, схемы БД, API и плана (или правки).
2. **Dev-вход.** Разрешаешь кнопку «Войти тестовым пользователем», которая работает только при `AUTH_DEV_LOGIN=true` и никогда в production? Без неё локально и в e2e-тестах не войти, пока нет ключей. Это техническая заглушка, ТЗ её прямо не разрешает — поэтому спрашиваю.
3. **Ключи входа:** Steam Web API key, Google OAuth Client ID и Secret, токен и username Telegram-бота. Есть уже или подключаем позже? Важно: Telegram Login Widget работает только на домене, привязанном к боту (`/setdomain`), на `localhost` он не откроется — для проверки нужен домен или туннель.
4. **Логотип.** Эмблему (открытый кейс с прицелом) вырежу из SVG для фавикона и мобильного хедера. В файле буквы собраны из множества отдельных кусков, и на тёмном фоне видны тонкие «швы» между ними — склею контуры сам или пришли исходник (AI / Figma) с объединёнными контурами.

## Правила баттлов (к этапу 5)

7. **«Участвовать скинами».** Предлагаю: оплата входа выбранными скинами = их автоматическая продажа по текущей цене + списание стоимости входа, остаток остаётся на балансе. Дропы проигравшего видны в его истории со статусом «проигран в баттле» и уходят победителю. Ок?
8. **Раздел выигрыша в 2×2.** Вариант А: каждый победитель забирает свои дропы и дропы соперника из парного слота — прозрачно, без конвертации. Вариант Б: весь выигрыш продаётся в гемы и делится поровну. Что выбираешь?
9. **Ничья** — решается дополнительным provably fair броском. Ок?

## Решено

- **Валюта** — внутренняя, «гемы», 100 гемов = $1, курс — в настройках (правка ТЗ от 2026-11-17, раздел 12.1).
- **Шапка с пунктом «Грузы»** (2026-11-26) — подписи меню с 1720px, плашка — сетка «1fr auto 1fr», меню всегда ровно по центру шапки; на 1536–1719 — только иконки с подсказкой; «Грузы» с иконкой-парашютом — после «Баттлы»; между пунктами: ниже 1280 — 24, 1280–1719 — 48, 1720–1879 — 32, от 1880 — 48.
- **«Грузы» в футере** (2026-11-26) — пятая ссылка в столбце разделов, после «Баттлы»: на планшете футер — единственная навигация по разделам, а гостю на телефоне грузы иначе не найти.
- **Минимум продаж у грузов** (2026-11-26) — как в брифе: у сидовых грузов минимума нет, по таймеру груз приземляется, если продано хотя бы одно место. Минимум с возвратом гемов (раунд закрывается без победителя, участникам — возврат и уведомление) задаётся у шаблона груза в админке; риск недопроданных раундов (одно место «Лёгкого груза» за 153 гема может забрать приз за 13 700) — на решение владельца.
