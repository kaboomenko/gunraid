# GunRaid — план этапов

> Статус: **предложение этапа 0.** Нумерация — как в разделе 15 ТЗ.

Каждый этап заканчивается одинаково: проект поднимается `docker compose up --build`, тесты зелёные, коммит и push в рабочую ветку, короткий отчёт «что готово / что дальше / что нужно от тебя».

---

## Этап 1 — Каркас

- Монорепо: pnpm, Turborepo, TypeScript strict, ESLint + Prettier, CI в GitHub Actions (lint, typecheck, тесты).
- Docker Compose: caddy, web, api, worker, migrate, postgres, redis; `.env.example` со всеми переменными.
- БД: миграции и сиды для `games`, `users`, `auth_identities`, `sessions`, `user_game_profiles`, `user_access_log`, `settings` (включая курс гемов), `admin_audit_log`; демо-админ.
- Вход: Steam, Google, Telegram (+ dev-вход, если согласуешь), привязка нескольких способов к одному аккаунту, access/refresh-токены, выход со всех устройств, роли, подтверждение 18+.
- Переключатель игры: URL `/standoff2/…` и `/cs2/…`, cookie, поле профиля.
- Хедер (логотип, переключатель игры, баланс в гемах с подсказкой «100 гемов = $1», вход), футер, мобильный таб-бар, место под ленту дропов.
- Дизайн-система: токены, шрифты, рубленые углы, кнопки, карточки, модалки, формы, `GemIcon` и `GemAmount`; витрина `/dev/ui`.
- i18n (`ru`), плюралы «гем / гема / гемов», проверка на «сырой» текст в JSX.
- Тесты: подпись Telegram, проверка Steam OpenID, ротация refresh и обнаружение повторного использования, guards ролей.
- **Проверка:** поднять проект, войти, переключить игру, выйти со всех устройств.

## Этап 2 — Каталог, профиль, инвентарь, ledger, тестовое пополнение

- Редкости (CS2 по ТЗ, Standoff 2 — по твоему списку), типы, модели, коллекции; по 40–60 демо-предметов на игру с ценами в гемах и SVG-плейсхолдерами.
- «Все предметы» (SSR, фильтры, сортировка, поиск, пагинация) и страница предмета.
- `PriceProvider` (заглушка: БД / CSV) и сервис CSV-импорта (цена в гемах или в долларах с пересчётом по курсу); интерфейс импорта — на этапе 7.
- Ledger и кошелёк: блокировки, идемпотентность, сверка баланса.
- Пополнение: `MockPaymentProvider` (успех / ошибка, вебхук с подписью), `FxRateProvider`-заглушка, котировка «сколько гемов будет начислено» до оплаты, окно пополнения с курсом «100 гемов = $1».
- Профиль: шапка, статистика, настройки (trade-ссылка CS2 с проверкой формата, ID Standoff 2, звук, «быстро»), публичный профиль.
- Инвентарь: мультивыбор, сортировки, сумма выбранного, продажа одного / выбранных / всех (демо-предметы выдаёт сид).
- Тесты: конкурентные списания и зачисления, двойной вебхук, повтор `Idempotency-Key`, пересчёт котировки, сверка баланса.
- **Проверка:** пополнить тестово в разных валютах, увидеть гемы на балансе, продать предметы, сверка сходится.

## Этап 3 — Кейсы, provably fair, лента дропов

- Категории, кейсы, ревизии состава; открытие x1–x5, рулетка, «быстро», звук; окно результата: продать / оставить / открыть ещё.
- Бесплатные кейсы (по уровню и по кулдауну), лимитированные (тираж и счётчик в реальном времени).
- Provably fair: пары сидов, ротация, страница проверки с инструментом в браузере.
- Лента live-дропов, онлайн, статистика сайта, баннеры.
- RTP кейса (функция в `game-core`; в админке — на этапе 7).
- Сиды: 8–12 демо-кейсов на игру (RTP около 90 %).
- Тесты: векторы provably fair, распределение по шансам, гонки открытий (баланс, тираж, кулдаун), идемпотентность.
- **Проверка:** открыть кейсы обеих игр, проверить результат на странице Provably Fair.

## Этап 4 — Апгрейд и контракт

- Апгрейд: ставка предметами или гемами с баланса, подбор целей, кнопки x1.5 / x2 / x5 / x10, круговой спиннер с шансом.
- Контракт: 3–10 предметов, диапазон результата, анимация «переплавки», история.
- Настройки комиссий и лимитов — в `settings` (интерфейс админки — этап 7).
- Тесты: формулы и ограничения, статистическая проверка RTP, один предмет в двух параллельных операциях.
- **Проверка:** апгрейд и контракт с результатом, проверяемым через Provably Fair.

## Этап 5 — Кейс-баттлы в реальном времени

- Лобби 1×1, 1×1×1, 1×1×1×1, 2×2; режимы classic и crazy; набор кейсов с повторами; оплата входа; боты; отмена с возвратом.
- Движок раундов в воркере, синхронные рулетки, список активных с фильтрами, история, страница завершённого баттла с повтором.
- Provably fair для каждого раунда.
- Тесты: детерминизм, определение победителя во всех форматах и при ничьей, гонка за последнее место, возвраты, восстановление после перезапуска воркера.
- **Проверка:** сыграть баттл с ботами на телефоне и в двух вкладках одновременно.

## Этап 6 — Бонусы

- Колесо фортуны (призы и веса, кулдаун, условия доступа, история), промокоды (все типы и ограничения, партнёры-блогеры), бонус за первое пополнение, ежедневный бонус со стриком, уровни и XP с наградами, рефералы, лидерборды с призами, ачивки, уведомления (колокольчик).
- Тесты: лимиты промокодов под конкуренцией, кулдауны, веса колеса, реферальные начисления, финализация лидербордов.
- **Проверка:** покрутить колесо, активировать промокод, получить ежедневный бонус и награду за уровень.

## Этап 7 — Вывод и админка

- `WithdrawalProvider`: CS2 — заглушка P2P-маркета (статусы, отмена сделки в течение 7 дней), Standoff 2 — ручной поток с подтверждением оператора и таймаутами; очередь с подтверждением.
- Антифрод: задержки, лимиты, флаг подозрительного аккаунта, связанные аккаунты по IP и устройству.
- Админка: дашборд (пользователи, пополнения, выводы, GGR, RTP факт / цель по режимам), каталог (предметы, редкости, CSV, массовое изменение цен), редактор кейсов с живым RTP, настройки режимов и курса гемов, курсы валют оплаты, бонусы, пользователи (история, ledger, бан, корректировка с обязательной причиной), выводы, аудит-лог; роли support / admin.
- Тесты: машины состояний вывода, RBAC, аудит.
- **Проверка:** вывести предмет каждой игры через очередь; настроить кейс, бонусы и комиссии без правки кода.

## Этап 8 — Полировка

- Мобильная доводка, анимации, звуки, SEO (meta, Open Graph, sitemap, robots), FAQ, правовые страницы (плейсхолдеры с пометкой `TODO: юрист`), cookie-баннер, кнопка поддержки.
- Playwright: все сценарии раздела 16 ТЗ на мобильном вьюпорте; k6: нагрузка на открытие кейсов, баттлы, WS; расширенные конкурентные тесты.
- **Проверка:** критерии готовности из раздела 16 ТЗ.
