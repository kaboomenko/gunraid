# GunRaid

Сервис открытия кейсов, апгрейдов, контрактов и кейс-баттлов со скинами для **Standoff 2** и **CS2**. Внутренняя валюта — гемы (100 гемов = $1).

**Статус:** этап 0 — архитектура на согласовании, кода ещё нет.
